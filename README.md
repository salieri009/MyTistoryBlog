📝 개인 블로그를 위한 Github
이 저장소는 개인 블로그의 디자인 및 기능 개선을 위해 만들어졌습니다.
이곳에 작성되는 HTML, CSS, JavaScript 코드들은 블로그에 직접 반영되며, 다양한 UI/UX 실험과 꾸미기 작업을 수행합니다.

📌 주요 목적
- 블로그 커스터마이징 (HTML/CSS)
- 스크립트 기능 테스트
-디자인 레이아웃 실험

📂 구성 예정
```
/css: 블로그에 적용될 스타일시트
/html: 테스트용 마크업 구조
/js: 추가 인터랙션 및 기능 구현
```
